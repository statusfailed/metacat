# metacat

Metacat is a categorical theorem prover built with
[open hypergraphs](https://github.com/statusfailed/open-hypergraphs-rs).

## Development status

The original checker and command-line interface have been removed while the
project is prepared for checker v2. The retained library currently provides
the single-sorted theory syntax and resolver.

The intended zero-arity monoid syntax is sketched in
[`demos/monoid.hex`](demos/monoid.hex).
